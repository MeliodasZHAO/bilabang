# 公众上线与合规落地清单

本文件记录 2026-09-08 的开发边界及上线依赖。不是法律意见或资质审核结论。

## 产品与身份

免账户投稿与公开匿名可以保留，但后台应有真实身份验证及可审计的身份关联。注册用户以昵称展示。接入国内短信服务和适用身份核验服务，发送/核验在服务端完成，验证码采用安全随机数、哈希存储、次数限制，身份凭据绑定用途并一次消费。对普通注册、免账户投稿和管理员采用不同权限。正式管理员必须采用独立安全认证；Meos / meos 仅为本地测试入口。

依据：[现行网络安全法第二十六条](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm)、[互联网跟帖评论服务管理规定](https://www.cac.gov.cn/2022-11/16/c_1670253725725039.htm)。先审后发是本站的运营选择，不能代替身份核验。

## 图片与内容

接入私有对象存储和队列。上传先检查真实格式、文件大小、像素、重编码、去 EXIF，再进行图片内容检测和人工审核。审核通过才进入公开存储或通过授权访问层提供。下架需要撤销公开访问并清除 CDN 缓存。

明确禁止偷拍、如厕中人物、隔间隐私、暴露身体、盗图、私宅和敏感设施位置。建立人工举报、侵权删除、申诉、操作审计和应急下架机制。自动审核误报/漏报必须有人工复核。

不把远程风景示意当成实拍证据，不伪造排名。地点合并需审核名称、地址和距离，保留原投稿来源、评分去重及合并撤销记录。当前后台支持通过、拒绝、下架、标记举报已处理、字段修订、版本冲突保护与公开/内部审核说明；尚无地点合并。

## 定位与全球覆盖

本地版本已接入 Leaflet / OpenStreetMap 地图选点与按需设备定位，提供全球地区目录搜索，保存 WGS84 公共地点坐标；尚未接入正式国内地图供应商或地址地理编码。上线前选择具有适用资质和海外覆盖授权的供应商，确认境内 WGS84 / GCJ-02 / BD-09 转换边界，不将不同坐标系混存。境外地点与境内地点仍要统一内容审核。

向地图服务商和属地主管部门核实定位、用户上传标注、地图数据库、审核地图、审图号和测绘资质的适用要求。接入 SDK 不自动免除平台义务。[地图管理条例](https://www.gov.cn/zhengce/zhengceku/2015-12/14/content_10403.htm)

## 隐私与数据

生产采用境内数据库/对象存储作为初始方案；减少跨境服务依赖。用户当前定位应按需、单独授权，拒绝后仍可手动选择地点。不收集连续轨迹。身份信息独立加密、最小权限，审计访问。完善隐私协议、服务协议、第三方 SDK 清单、保留期限、查询更正删除、账号注销、未成年人处理及联系渠道。网络日志保留期限按适用法律执行，不能与业务信息无限保留混同。

[个人信息保护法](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3ef1e889c1e644d4b65b5f5c7f432386.html)

## 备案、资质与榜单

确认运营主体和业务类别后，向接入商/属地管局办理适用 ICP 备案或许可，开通后办理公安联网备案；核实社区功能对主体的要求。备案号需真实可查，不使用占位假号码。后续收费或广告业务需重新评估许可与商业规则。

[工信部服务指南](https://hunca.miit.gov.cn/bsfw/bszn/art/2024/art_7ef0d8bd3b0d433ba4b9b277f883f74d.html)、[公安联网备案依据](https://banshi.beijing.gov.cn/pubtask/task/1/110105000000/cc840bb3-08d0-431b-a294-ecfed38f5a4b.html?locationCode=110105000000)

公开评分公式、样本量及日期，提供申诉纠错。根据最终服务属性判断排序精选算法是否需要备案/安全评估，不能以公式简单、非个性化为由断言豁免。[算法推荐管理规定](https://www.cac.gov.cn/2022-01/04/c_1642894606364259.htm)

## 验收顺序

1. 本地完整流程与边界测试。
2. 真实短信、真实审核、私有存储、地图接入，在测试环境验收。
3. 生产构建、代理 HTTPS、Cookie、安全头、大小限制、恢复备份、日志、限流与恶意上传验收。
4. 运营规则、资质核实、备案、隐私及投诉渠道就绪。
5. 准备少量真实授权投稿，人工核实地点后开放。

截至本地 v3 复核，第 1 阶段已有自动与浏览器验证，第 2 阶段地图选点已在本地实际验证；真实身份服务、测试/生产环境与运营接入仍未完成。本地模拟身份不能直接暴露到公网。当前外部依赖见 production-handoff.md。
