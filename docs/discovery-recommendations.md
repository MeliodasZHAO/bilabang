# 地区推荐、近期热度与短片

首页默认可用编辑精选。浏览器获得有把握的网络省市后，优先显示同城，再按同省选取。有需要时可切换省份或看全国。使用 IP 反推的省市不等于实际位置，尤其在代理、移动网络下。

`/_discover` 不缓存，只返回目录中可用的粗略省市和热度地点 ID。入口由 Caddy 将连接 IP 覆盖到内部头，后端只监听 `127.0.0.1:5198`。查询在服务器本地完成，不保存 IP。关闭访问统计也停止自动识别；手选仍然可用。

每十分钟从现有 Caddy 日志汇总近七天的精选详情打开。同一浏览器对同一地点只取最后一次，QA 不计。至少三个不同浏览器才参与排序，打开越新权重越高，权重每两天减半。首页的推荐序可以变化，30 城编辑分与排名保持独立。流量不足时显示编辑精选；线上数据不会混入验收样本。

短片收录在 `src/data/discovery-films.json`，保留原平台、作者或项目方、发布日期及可核对的原文。抖音短片使用官方播放器，部分媒体视频在原文播放。阿西里西的小红书原帖在部分网络中可能要求 App 登录，网页可从项目报道或公开播放器查看。站内封面沿用同地点实拍，未取得可展示封面的项目用地名标题卡。未确认现状的限时项目不放进到访榜。

用 `node ops/check-discovery-media.mjs` 检查现有片单。发现候选、核片与批次发布见 [短片采集和核片流程](discovery-media-workflow.md)。

推荐服务运行包包含 `ops/discovery-service.mjs`、`src/data/editorial-places.json`，以及来自 [ip2region](https://github.com/lionsoul2014/ip2region/tree/f1781b7f9b7a17c96246433d83804404f0a22120) 的 IPv4/IPv6 XDB、官方 JavaScript binding 和许可证。部署包使用该提交的文件，XDB 仅在服务器后端存放。unit 见 `ops/bilabang-discovery.service`，Caddy 路由在 `ops/Caddyfile.traffic`。当目录更新时同步换服务包，以使省市和地点白名单生效。服务失败时前端仍保留手动地区选择、短片与编辑精选。
