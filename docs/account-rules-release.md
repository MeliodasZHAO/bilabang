## 部署与回滚边界

继续使用现有 npm lockfile、`npm run build:edgeone`、GitHub main 自动部署、香港 Node/SQLite/Caddy，未新增服务或环境变量。部署前需要同步安装仓库的 `ops/deploy.sh` 到服务器 `/usr/local/bin/bilabang-deploy`，新版健康检查应为 schema 2。
