# 社区持久化部署

用户于 2026-09-08 明确确认：在当前 Sites 接入 D1 和 R2，保存地点、用户、评论、评分与审核信息。此授权不要求再次确认本次生产表创建及已批准来源资料导入。

## 运行方式

保留本地 Express / SQLite 流程。`npm run build:hosted` 构建同一前端和 Cloudflare Worker；`dist/server/index.js` 为入口，`dist/client` 为静态资源，Sites 插件复制绑定与迁移。

`.openai/hosting.json` 的 D1 绑定为 DB，R2 绑定为 FILES。Drizzle 生成的迁移只建结构；应用启动不创建、修改或清空表。已应用迁移不可修改。管理员可重复导入既有七条来源资料，使用 INSERT OR IGNORE，不覆盖已修订内容。

## 身份与权限

公开浏览、游客投稿不需要账户。评论与回复使用 Sites 的 ChatGPT 登录，服务端只认平台注入的身份头；本站不提供公开 Meos/meos 密码登录。管理员以服务端 ADMIN_EMAIL 配置和平台验证邮箱匹配，前端传入 role 无效。昵称默认匿名化，不公开邮箱。

RATE_SALT 用于对按小时的访问来源限流标识做摘要，数据库不保存原始 IP。BOOTSTRAP_KEY 仅用于首次资料导入与 R2 写读删除验证；初始化完成后移除该环境变量并重新发布，初始化入口即失效。以上敏感值不写入源码或本地文件。

## 评论和图片

到访评价需要四维评分、到访日期和正文；现场信息只记录事实，不参与评分；回复仅针对已公开的主记录。新内容待审核，作者能看到自己的待审记录，其他访客不能读取待审照片。下架主记录后其回复与配图也不对外公开。管理员处理使用版本比较并记录公开原因、内部备注。

每个账户对每个地点，取到访日期最近的一份已审核评分；同日按发布时间取最近一份。历史到访保留，人数不叠加。五位有效评价后才进入榜单；不虚构启动评分。

图片客户端重新编码缩放并移除 EXIF；服务端检查 JPEG 内容、尺寸和危险元数据，不依赖文件扩展名或请求声明的 MIME。文件保存于 R2，关联与说明保存于 D1。数据库写入失败时清理本次 R2 对象。投稿和评论使用请求标识避免重试重复写入。

## 验证

`tests/hosted-runtime.test.js` 直接运行编译后的 Worker，在 workerd / D1 / R2 环境验证：游客权限、无扩展名上传、私有照片、审核、乐观并发、唯一计分、回执、重启后数据与图片保留。部署后还需确认匿名请求、平台身份头保护、数据库表、初始化资料、图片存储和再次发布后的数据保留。

这不代表国内正式运营条件已经全部齐备。ChatGPT 登录对于国内公众存在使用门槛；手机号或其他国内身份方案、运营主体信息和正式地图服务仍需进一步落实。
