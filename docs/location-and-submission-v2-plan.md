# 地区筛选、地点创建与真实资料收录 v2（已授权实施）

> 2026-09-08 已获用户授权并完成首轮实现，实际交付与剩余边界见 [v2-delivery.md](v2-delivery.md)。下文保留原设计方案。

## 当前检查

现有表单只有自由文本 country / city，不能可靠区分行政区；lat / lng 和到访日期一律必填，无法表达没有地图点位和未亲自到访的公开资料。照片只存一种 kind，无法分别表示入口、路线、设施与风景。2026-09-08 只读检查：主数据文件暂无地点记录。本次尚未改动代码或数据库。

## 1. 地区与筛选

- 国内以国家 → 省/自治区/直辖市 → 地级市/自治州 → 区/县/县级市为基础，使用稳定地区 ID、父级 ID、显示名及别名。直辖市在交互中合并冗余层级。
- 境外按当地真实行政层级显示州/省、城市/自治体、区。没有对应层级时可跳过，不编造中国式区县。
- 桌面采用地区选择浮层；手机采用底部面板。支持搜索“南山区”“深圳南山”并显示完整路径，解决重名区县。
- 任意层级可选“全市/全区”；切换上级清除不匹配下级；显示结果数和可移除筛选标签。选择待确认、确认应用、取消退出相互分离。
- 区域筛选与评分维度、文字搜索组合使用，筛选写入 URL，刷新/后退可恢复；零结果支持扩大到上一级，不擅自改变用户的地区选择。
- 地区不明的数据放入“区县待核实”，不混入任何具体区。创建时未覆盖的地名可提交待审核补录，公开前规范归属。
- 首批地区目录覆盖真实收录地点及其父级；国内完整目录使用可追溯版本的数据源接入，不宣称凭几条城市样例支持全国所有区县。

## 2. 同一创建流程，两种模板

流程：选择模板 → 地点与找路 → 照片与资料 → 预览确认 → 提交审核 / 管理员审核发布。

**实地分享**：要求到访日期、至少一张自有或获授权实拍；不强迫上传者当场评价。普通网友免创建账号但须完成验证；管理员已登录直接进入同一表单。

**公开资料收录**：要求来源 URL、发布者、核查日期、原创摘要；不要求虚构到访日期。图片无授权可以暂缺，展示“待补实拍”，而非套用图库照片冒充现场。

管理员后台与前台均提供“添加厕所”。管理员提交默认进入待审，也可在预览后选择“确认审核并发布”；发布者与审核操作均记入审计。同一套数据校验适用于手动添加和种子资料导入，不靠直接写库绕过规则。

## 3. 必填与选填

| 字段 | 实地分享 | 资料收录 |
| --- | --- | --- |
| 名称、规范地区、地点介绍 | 必填 | 必填 |
| 定位方式 | 必填 | 必填 |
| 详细位置/地标说明 | 必填 | 必填，缺少入口时标记待核实 |
| 厕所坐标 | 有准确坐标时填写 | 仅来源明确提供时填写 |
| 参考地标/入口坐标 | 可选，与厕所坐标区分 | 可选，不推断为厕所坐标 |
| 找路步骤 | 只有大致位置或无坐标时必填 | 无法核实时明确缺失，不编造 |
| 到访日期 | 必填 | 可选，仅亲自到访才填 |
| 实拍照片及类别 | 至少一张 | 可选，上传须明确权利 |
| 来源、发布者、核查时间 | 可选 | 必填 |
| 开放时间、费用、是否需门票 | 可选，默认为未知 | 可选，附来源 |
| 无障碍、母婴、洗手、纸巾、停车 | 可选：有/无/未知 | 可选：有/无/未知 |

必填不能靠星号暗示：字段标签、帮助文字、逐步校验、错误摘要和错误定位都需要实现。上一步保留内容；提交期间防重复点击；可保存草稿；退出有未保存提示；验证临近提交再进行，过期后只需重新验证，不清空资料。

## 4. 无地图点位与图文找路

定位方式：准确厕所点 / 附近地标点 / 仅文字位置。坐标记录坐标系、来源和精度说明；不填坐标存 NULL，不存 0,0，不以城市中心伪装厕所位置。

找路模板提示：从哪里出发 → 朝哪个方向 → 距离/时长（知道才填）→ 看到什么 → 哪个入口/哪层楼。支持多条步骤、关联路线照片、逐图说明。例子仅作为提示，不预填成事实。

照片逐张标记：厕内视野、建筑外观、入口标识、沿途路线、内部设施、周边景观。可以选择封面、排序、删除，并检查是否只上传周边风景却宣称厕内视野。

详情页单独显示“怎么找到它”，展示最后一段路、入口照片、参考地标与定位可信程度。参考点的操作文案为“前往附近地标”，不能叫“导航到厕所”。无坐标时提供复制位置说明，不显示可用的精确导航。

## 5. 数据结构变更范围

- 新增规范地区目录及父子层级；地点关联地区 ID 并保留原始地名供纠错。
- 地点扩展定位类型、可空坐标、参考点、入口/楼层、找路步骤、设施三态、资料类型与来源核查字段。
- 照片扩展逐图类别、说明、顺序、封面、来源/授权信息及关联路线步骤。
- 增加草稿/发布状态对应的校验规则，投稿与审核关联真实操作者；迁移版本和可回退备份。
- 已有评分继续保留。资料收录不能生成用户、到访或评分，零评价地点不进入正式榜单。
- 兼容旧格式记录，不擅自猜区县或批量覆盖旧内容；迁移前备份，未知层级保持未知。

## 7. 本轮验收

地区跨层切换/重名/直辖市/境外无区级/零结果/刷新恢复；手机选择与键盘操作；两模板前后端必填一致；无坐标与参考点区别；逐图分类和路线关联；管理员前后台同表单；草稿恢复与验证码过期保留；重复地点提示；重复提交与导入幂等；原有记录与评分不受损；来源链接、资料年份、无授权图空态；隔离数据库完整 HTTP 与真实浏览器流程。
