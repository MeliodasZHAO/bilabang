# 蓝白城市摄影图鉴改版

2026-09-09，直接修改现有 React/Vite 项目，沿用 npm 与现有依赖。

## 实际修改

- `theme.css`：统一瓷白、深色文字、标识蓝与状态色；系统字体，8/10/12px 控件、照片、弹窗圆角。
- `atlas.css`、`controls.css`：导航、按钮、首页开场、筛选、卡片、详情和浮层。停用旧 playful.css 的黄色、厚阴影和大图主题。
- `main.jsx`、`PlaceCard.jsx`：简短开场与单套搜索，3/2/1 列地点网格；名称、地区、简介、真实评分依次展示。无评价不显示零分，普通浏览不显示名次。
- 发现页在评分排序相同的情况下优先展示已有照片的地点；评分算法、榜单排序值和入榜阈值不变。无真实地点时保持空状态，不再填入旅行示意地点。
- `PlaceGallery.jsx`、`gallery.css`：根据真实照片数量排单图、双列或三图拼贴，手机4:3主图；保留逐张选择、原图、作者、来源与授权信息。
- 详情按标题、照片、简介与实用信息、评分评论组织；桌面2:1内容/地点资料，手机地点资料先于长讨论。
- `supporting.css`、`CommunityReviews.jsx`：自然评论列表、32px昵称首字头像、清楚的发表评论入口；统一登录/注册、协议确认、投稿、地图选点、管理、联系和法律页。
- `SubmissionWizard.jsx`：原照片字段补常驻标签，字段、上传限制与验证逻辑不变。
- `RegionPicker.jsx`：筛选移动到左侧后修正浮层定位，按视口可用高度约束；手机浮层不越界，保留 Escape 和返回焦点。
- `index.html`、favicon：匹配新字标与主题色，移除旧概念背景图的无效预加载。隐私说明中关于旧首页概念图的一句描述同步为现有照片署名说明。

## 保持不变

数据库、schema、迁移、API、认证、协议同意记录、审核、评论同步周期、评分与限流没有更改。
原有 URL、全球/市/区筛选、分享流程、最多6张图片、地图服务、来源资料和 GitHub 自动部署保持。
本次没有添加地点、图片、评论、评分、认证或虚构的收录数量。现有地图选点保留；项目没有独立地图页，本次没有新建地图产品。

## 实际验证

- `npm test`：38/38通过，包括认证、评论/图片、审核、注册规则、备份恢复、地区精度和评分阈值。
- `npm run build:edgeone`：通过。仍有主包超过500KB的体积提示，此轮没有扩大到代码分包重构。
- Windows Chrome：360、390、768、1280px检查首页、详情、投稿、联系、隐私、登录/注册；没有横向溢出。
- 390×844首页首张真实地点名称底部约809px，首屏可见照片与名称。
- 上海虹口筛选实际返回2处对应地点；地区/Select/登录支持Escape，关闭后焦点返回。
- 地图缩放与取消选点正常，署名保留；投稿、协议复选框与菜单可操作。
- 真实详情图片加载正常；0/1/2/3/6张图片的独立浏览器夹具共20种视口/布局组合通过。夹具不写入生产数据。
- 无图、图片404、搜索空结果、API503错误与重试已验证。故障由本地浏览器拦截模拟，解除后恢复真实公开数据。

浏览器视觉预览只读取公开数据，不创建账号、不提交生产评论或投稿。手机结果是浏览器视口检查，不等同于 Android/iPhone/微信真机或大陆各运营商访问测试。
