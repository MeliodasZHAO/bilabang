# 公网预览与持续更新

> 本文描述最初的静态预览版本。用户已批准升级 D1 / R2 社区版；当前构建与接入方式见 `hosted-community.md`，发布社区版使用 `npm run build:hosted`。

站点：https://bilabang-scenic-toilets.wangjiaze203.chatgpt.site

当前发布为只读公开预览。复用主站页面、筛选、详情与地图选点草稿，公开 7 条有来源的地点资料与许可图片。评论、注册、登录、投稿提交暂未开放；没有伪造评分。界面标注预览状态，草稿留在访问者本机。

## 数据边界

`npm run build:public` 从维护的 `src/data/source-places.js` 和图片署名生成公开目录，不读取 SQLite，不打包账户、会话、投稿、备份、验证码或环境文件，不创建生产数据库。全球目录按需加载；国家与中国区县可立即浏览，首次搜索海外城市会下载完整目录。

## 更新

修改同一项目源文件，运行本地测试与 `npm run build:public`。使用 `.openai/hosting.json` 中现有站点标识，推送经过验证的源码并将 `out` 打包保存为新版本、发布至同一地址。勿重复创建站点；源码凭据仅临时用于推送，不存进文件。`npm run build` 和 5186 本地服务继续使用原有本地架构。

评论图片、实时信息与可信评分仍是下一阶段重点。上线写入前，另行确认生产数据库方案并接入正式身份验证、存储和审核；本次公网预览不等于已完成国内经营合规或地图服务审核。
