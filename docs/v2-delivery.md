# 地区与投稿流程 v2 · 2026-09-08

已获用户“开始吧”授权后实施数据语义扩展及真实资料导入。继续使用现有 SQLite JSON payload，新增记录带 schemaVersion=2；不对旧记录猜测区县、不删除旧数据。导入前使用 VACUUM INTO 生成一致性备份，位于 data/backups。七条资料使用稳定 ID，二次导入新增 0 条。

## 已实现

- 大陆省市区县目录、直辖市合并层级、地区全文路径搜索、层级浏览、待选与确认分离、数量、清除、空结果扩大范围、地区 URL 与后退恢复。搜索及排序也保存到 URL。
- 统一四步创建：实地分享 / 资料收录；管理员与游客使用同一组件、相同服务端校验。管理员可提交待审或预览后直接发布，保留审计。
- 三种定位语义：厕所精确坐标、参考地标坐标、文字路线。缺坐标存 null；不编造到访日期。入口、楼层可写在详细位置，路线每行一步，可复制。
- 照片逐张用途、说明、作者、来源、许可，封面调整与移除。授权实拍要求与无图片资料收录分别校验；服务端继续解码图片并去 EXIF，不依赖临时文件扩展名。
- 设施选填有 / 无 / 不清楚；默认不假定齐全。文字草稿本机恢复，验证过期可重做；照片在界面明确告知关闭后须重新选择。
- 重复请求 ID 在同一投稿身份下返回既有回执。公共接口不暴露请求身份及投稿者内部 ID。来源资料不自动评分。
