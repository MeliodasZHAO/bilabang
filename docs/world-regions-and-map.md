# 全球地区与地图选点

2026-09-08 本地实施。用户明确同意本地数据扩展。

## 地区目录

大陆既有行政区目录保持原ID和层级；海外与港澳台补充源自 [CSC 数据集](https://github.com/dr5hn/countries-states-cities-database)，固定版本 `b3b49250ff3906f6119e16c088c0053a2c972926`。原项目的 `country-state-city` GPL npm 包已移除，未使用其代码；采用上游 ODbL 数据，转换脚本为 `scripts/prepare-world.mjs`。

- 247 个国家或地区根节点；港澳台仍属于中国目录，不作为独立国家列出。
- 154142 条补充省州/城市/地区目录记录，部分与原ID合并；这个数字不是厕所数量，也不表示覆盖全球每一个区县。
- 原文名称、英文别名和中文国家名称可搜索；城市主要使用当地或英文名称，不假装全量中文化。
- 首都优先、重名地点显示完整上级路径；每页60条，支持分页，选到任一上级即可确认。
- 省州和城市坐标仅用于地图移动，绝不自动作为厕所入口写入投稿。
- 中国原有目录的时效和海外行政区差异依然需运营核对；目录缺失可填写待规范地区，管理员修正后再发布。
- 浏览器只下载根节点和所查页，不下载完整城市库；服务端建立目录索引。

衍生目录继续按 ODbL 公开。站内提供 `/region-data/world.json`、`/region-data/countries.json` 与 `/region-data/LICENSE.txt`。原数据库不包含用户投稿，两者分开存储；后续变更许可范围须按实际使用核查。转换脚本可重建，原始文件缺失时从固定版本下载。

## 地图

Leaflet 地图支持平移、缩放、鼠标点击、标记拖动、按需设备定位；确认前不写入表单。入口 / 参考地标有独立选项，参考地标需填写找路说明。城市搜索使用本站目录，没有调用公共 Nominatim 地址搜索接口。点位不反查或擅自更改行政地区。

本地使用 OpenStreetMap 标准底图，已真实加载验证。[底图使用政策](https://operations.osmfoundation.org/policies/tiles/)要求署名、可识别来源、尊重缓存并禁止批量离线下载；当前保留署名，使用浏览器缓存，没有预取或批量抓取。该公益服务没有可用性保证。全球地图当前采用 Web Mercator，极地超出约85度纬度时需手动坐标/文字描述。

正式国内版本仍需选择适用的地图供应商并确认备案、审图、坐标及使用条款。当前全球底图不代表已完成国内地图服务合规。不能将高德/百度坐标直接当WGS84存入；现有数据仍明确使用WGS84。

## UI 与验证

下拉框使用 Radix Select：选中标记、键盘方向键、滚动、Escape关闭、返回触发器焦点；在原生 dialog 内挂载浮层。地区面板根据空间向上展开，手机普通筛选采用底部面板，投稿内地区面板使用完整宽度展开。表单手机端单列，修正旧版两列造成的狭窄地区面板。

已在浏览器完成法国选择与刷新恢复、390px虹口筛选返回两处地点、Sydney地区选择与地图加载、Paris搜索移动地图并点击回填坐标。更完整的公开部署、真实用户试用和商业地图服务验证仍待后续。
