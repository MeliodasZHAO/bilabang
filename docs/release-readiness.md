目标：可公开运行、可持续维护、有真实内容价值的风景厕所社区。良好反响需真实用户反馈验证，不能用代码构建成功或演示截图代替。

## 当前已验证

- 本地网站运行，七条有来源的地点、三张有许可的图片；没有伪造评分。
- 实地/资料模板共用服务端校验；游客验证、账号评论、管理员发布在本地模式有集成测试。
- 省市区筛选、直辖市、重名地名、参考点与精确坐标区分已有实现。
- 2026-09-08 第二轮：11 项自动测试通过；生产构建通过。
- 非对象资料、错误字段类型、原型属性照片分类、布尔及纯空格坐标现在拒绝；不再由隐式类型转换得到 0 坐标。
- 手机端完整投稿预览可核对位置、路线、费用、设施、日期、来源；有对应步骤修改入口。浏览器实际走通预览与返回修改。
- 浏览器模拟 localStorage 写入抛 SecurityError 后，表单继续显示，可编辑，并提示草稿无法保存。未向主数据库提交测试数据。

- 第三轮：地点详情支持 `?place=稳定ID`，可以复制链接、直接进入、刷新恢复。页面标题使用地点名称；无效/未公开链接有明确不可用提示。

- 第五轮：构建版首页与地点链接输出服务端公开资料、标题、描述、Open Graph、可配置 canonical；无 JavaScript 也能读到地点与来源。未公开/下架/生产模式演示记录返回404，不输出对应资料。正式模式且配置 SITE_URL 才提供站点地图；本地 noindex 和 robots 禁止抓取。14 项测试通过，覆盖生产模式真实 HTTP、站点地图排除及 HTML 转义。
- 第六轮：一致性备份、文件哈希校验、恢复到新目录的工具完成；运行中主库已备份并在独立实例恢复读取七处地点。关联图片与篡改失败有隔离测试。生产依赖 npm audit（官方 npm registry）返回0个已知漏洞。详见 backup-and-recovery.md；尚不代表完整安全审计或异地灾备。

## 仍需完成或加强（不视为已发布）

1. 内容价值：增加国内多城市可信地点、授权照片与实地路线；整理更新频率、过期信息与纠错处理。当前样本不足以支持有效榜单。
2. 核心体验：完整筛选历史、重复地点提醒、网络中断与并发重试。草稿图片、回执保存、地点 URL 与匿名转登录返回已完成首轮验证，仍需纳入长期自动回归。
3. 运营闭环：管理员字段修订与地区规范化、退回原因、举报处理证据。图片复核和本地资源下架权限已改善；未来 CDN 接入需另验撤销与缓存。
4. 安全与可靠性：真实验证服务、权限与会话策略、生产管理员认证、请求幂等与并发场景、异常输入、私有上传、审计、备份恢复演练、监控和日志。
5. 无障碍与性能：键盘全流程、焦点管理、对比度、触摸交互、不同屏宽与慢网络、图片载入和错误状态；不把一次截图当作全站验证。
6. 公开发现：服务端详情、元信息和站点地图已实现；正式域名后的搜索引擎收录与平台分享卡片仍需实测。真实服务条款和联系渠道未就绪。
7. 国内上线：运营主体、域名、正式服务凭据、备案及适用业务要求、隐私与内容审核运营。详见 launch-plan.md，尚无完成证据。
8. 外部反馈：测试环境试用、真实用户是否找到入口/完成投稿/理解评分的反馈；未开展，不能声称已有良好反响。

后续修改继续以实际运行结果为依据。新增数据库语义或生产数据操作遵循用户审批要求；已授权 v2 数据范围内的修复继续执行。不得把本地身份模拟直接开放公网。
