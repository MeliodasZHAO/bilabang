# 必拉榜 · The Scenic Stop

发现与分享风景厕所的响应式 Web 应用。项目包含本地演示服务与 Sites 托管服务两条运行路径；目前尚未完成面向国内公众正式运营的全部验收。

## 托管版本与当前源码

- 公网地址：https://bilabang-scenic-toilets.wangjiaze203.chatgpt.site/
- 托管后端：`worker/index.js`，D1 保存用户档案、地点、评论和审核记录，R2 保存用户上传图片；登录使用 ChatGPT 平台身份。
- 当前源码包含统一的蓝黄视觉、独立厕所详情页、评论每 15 秒同步，以及全球地区筛选和投稿审核流程。
- 截至 2026-09-08，最新样式与独立详情页已通过本地检查，但发布平台文件上传超时，尚未更新到上述公网地址。GitHub 源码与公网部署状态需要分别核对。
- 点赞、收藏及个人中心仍为规划功能，尚未新增对应数据库表。

```powershell
npm ci
npm run build:hosted
node --test tests/hosted-runtime.test.js tests/hosted-scale.test.js
```

托管构建产物位于 `dist/client` 和 `dist/server`。`scripts/preview-hosted.mjs` 使用 5187 端口和隔离临时数据库进行浏览器测试；运行前检查端口空闲，它不是生产服务。运行方式、测试边界和迁移计划见 [社区运行说明](docs/community-operations.md)。

仓库保存源码、数据库结构、迁移文件及带来源说明的素材，不包含生产数据库、用户上传文件或部署密钥。推送 GitHub 不会自动部署，也不会同步生产数据。

## 本地演示服务

需要 Node.js 22.21 或更高版本。使用 Node 内置 SQLite（Node 22 会输出实验性功能提示）。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5186 。本地管理员 **Meos / meos**，登录后点击右上角“Meos · 管理”。默认仅监听本机，不占用既有服务端口。Vite 的 WebSocket 复用 HTTP 服务，不单开默认 HMR 端口。

```powershell
npm run build
npm test
npm start
```

`npm start` 运行构建产物，**关闭模拟验证、注册、登录、投稿和测试账户会话**。不要通过关闭该限制来直接上线。正式身份服务接入后需重新设计上线配置并验收。默认数据目录为 `data/`；支持环境变量 `PORT`、`DATA_DIR`。不要把 `data/`、`.env` 或 `output/` 提交到版本库。

`npm run preview` 使用构建后的网页提供完整的本地演示流程（仍使用模拟身份），适合在本机体验和性能检查。它同样不是公众上线模式。

构建版通过 `/?place=地点ID` 提供可分享详情，服务端输出公开内容与分享元信息。正式部署准备完成后可设置 `SITE_URL=https://你的真实域名`（仅 HTTPS 源站地址，不带路径），启用 canonical 与 `/sitemap.xml`。未配置域名或本地预览时保持 noindex，站点地图返回 503；这项配置不解锁身份服务，也不代表已经完成上线审批。

## 已实现

- 桌面 / 手机发现页、榜单页、搜索、国家地区筛选、5 种评分排序、空状态。
- 地点详情、多图查看、坐标、到达说明、到访日期、开放时间、收费说明。
- 免账户投稿：本地模拟手机号验证、最多 6 张图 / 每张 8 MB、回执查询。
- 图片基于真实文件内容检测，支持没有扩展名的上传临时文件；JPEG / PNG / WebP 重新编码为 WebP，去除 EXIF、限制解码像素。待审图片不公开。
- 注册普通账户、密码哈希、HttpOnly / SameSite 会话、登录退出、管理员与普通成员权限。
- 分项评分与评论：登录后提交，审核后公开。同一账户对同一地点更新原评价，重新进入审核。
- 管理后台审核地点、审核评价、下架、处理举报及审计记录。
- 频率限制、来源校验、SQL 参数绑定；正式模式拒绝模拟身份写入。

## 数据与范围

为使空项目无需安装数据库即可运行，首版本地采用 **SQLite + 本地私有图片目录**，不是之前设想的 PostgreSQL / 云对象存储生产部署。表包含 users、sessions、verifications、places、photos、reviews、reports、audit。真实上线需要迁移 PostgreSQL、对象存储及备份/保留策略，并单独核实数据迁移范围。

验证码是本地模拟值，在界面明确展示，5 分钟有效、最多 5 次错误尝试。测试手机号暂存本地验证码表，过期记录在后续发送时清理；不把它描述为已接入运营商实名校验。正式身份映射、手机号加密、找回密码、注销和删除机制尚未完成。

示意图片来自 Unsplash 的远程图片地址，明确标记为旅行灵感，不是厕所实拍，不进入数据库及实际评分。没有编造全球厕所排名、评价人数或精确景点位置。`src/demo.js` 的国家地区仅用于筛选演示，不是对照片拍摄地的确认。公众服务需要经过授权核实的地点与照片。

首页背景已改为内置 ImageGen 生成的厕所内望向山湖的概念图，界面明确标记 AI 生成。新文件和最终提示词见 [docs/hero-toilet-view.md](docs/hero-toilet-view.md)。

综合平均分 = 风景 40% + 卫生 30% + 到达 20% + 设施 10%。至少 5 份有效评价才有排名，排序采用 `(n × 平均分 + 5 × 3.5) / (n + 5)`；页面显示原始平均分。首版按所有已审核评价计算，尚未实现卫生分的近期衰减、设备反作弊或异常评分识别。

## 验证

`npm test` 包含评分边界和独立临时数据库的真实 HTTP 测试：无扩展名图片、非法文件、去 EXIF、审核前后访问、错误身份、跨来源写入拒绝、评价更新、举报、普通成员权限、退出会话、构建产物服务及正式模式关闭写入。

浏览器验收数据位于 `output/qa-data/`，与交付数据 `data/` 分离。截图位于 `output/playwright/`。验收服务仅临时运行，最终保留 5186 本地服务。

## 公众上线前必须完成的实际工作

见 [docs/launch-plan.md](docs/launch-plan.md)。现阶段仍缺：正式短信与身份提供方、国内正式地图服务配置、生产存储、自动内容审核、地点合并、删除注销与申诉处理、运营主体及备案信息。页面不伪造这些服务已可用。

## 本地 v3 改版

已获用户同意的本地数据扩展在非生产模式启动时先备份再迁移，生产不自动执行。新增 schema_migrations、identities、place_revisions、moderation_events，地点版本与验证用途/消费状态。管理员可修正资料、填写处理说明、查看修订记录。真实身份提供方仍需后续配置。

全球目录与实际地图选点、统一下拉控件见 [docs/world-regions-and-map.md](docs/world-regions-and-map.md)。`node scripts/prepare-world.mjs` 可从固定上游版本重建开放地区目录；无需在每次启动时下载。上线核对许可与底图服务条款。
